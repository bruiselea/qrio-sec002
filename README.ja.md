# SEC002 本体ファーム対策キット v0.1.0

日本語 | [English](README.firmware.en.md)

このページはQ-SL1本体へ適用するSEC002差分キットの説明です。全体の機能・必要なものは[トップREADME](README.md)、LAN中継の導入は[中継セットアップ](relay/README.ja.md)を参照してください。

最新ソースには別途[有線バックアップ・限定復旧キット](wired/README.ja.md)と[文鎮化原因の技術報告](docs/BOOT_FAILURE.ja.md)もあります。旧v0.1.0 ZIPには有線キットを含めていません。

**純正ファームを同梱しない、差分パッチ形式の配布用ツールです。未改造機へのSEC002全無線インストーラーは実験版です。**

Linux PCまたはラズパイのBluetoothから、所有する初代Qrio Smart Lock Q-SL1へ、配線なしでSEC002を導入する手順とコードを収録しています。WindowsからはSSHでLinux側のコマンドを実行できます。Q-SL1をWi-Fiへ直接つなぐ方式ではありません。

## 最初に読むこと

- 本体に電池があり、BLE広告が出ている未改造の`1.4.01`が対象です。電波が出ない文鎮を無線で直すツールではありません。
- 対応する起動配置はSS1=`0`、DS1=`0x580`。元DS1の26,845バイトのSHA-256が`4679b688063dac92d7c326f3e98ba429291bf1140afc2f4b96a1694cb8741c81`と一致する場合だけ進めます。別の版・配置・ハッシュは強制適用できません。
- SEC002は既知の無認証FWU用CIDと旧OTAを無効にします。**導入後のファーム更新・救済は有線UART限定です。** 所有者鍵があっても、この版は無線再更新を許可しません。
- 自動起動ロールバックはありません。広告開始前に停止した場合、無線だけの救済はできないため、[有線復旧の準備](docs/RECOVERY.ja.md)も先に読んでください。
- 施解錠・HomeKitの所有者鍵を作成・登録するツールではありません。既存の所有者データを保持しますが、新しい利用者のHomeKit連携は別に設定が必要です。

## 配線なしの導入

[WIRELESS_INSTALL.ja.md](docs/WIRELESS_INSTALL.ja.md)に、Linux/ラズパイの準備、検出、暗号化バックアップ、予備領域への転送、最終切替、確認の全コマンドがあります。各操作は対象MACを最初に明示し、その後は暗号化バックアップ内の個体識別子へ結び付けます。全体を読んでから実施してください。

受領したZIPはWindowsからLinuxへ`scp`で転送しても構いません。Q-SL1へUSB/UARTケーブルをつなぐ工程は初回の無線導入にはありません。すでにSEC002を入れた本体には無線導入コマンドを再実行しないでください。

## 同梱物

- `qsl1sec/`: Linux BLE転送、固定差分適用、ポータブル暗号化バックアップ
- `patches/sec002.json`: 独自の置換バイトと、元データ・出力の指紋。純正コード本体は含まない
- `patches/sec002-assembly.txt`: 追加処理の独自アセンブリ表現
- `tests/`: 合成データによるオフライン試験。Bluetoothは使わない
- `docs/`: 初回導入、復旧、検証範囲、公開時の手順
- `LICENSE`/`NOTICE.md`: 独自部分のMITと第三者の権利範囲

バックアップはscrypt＋AES-256-GCMで暗号化し、現在のWindowsアカウントに依存するDPAPI形式にはしていません。パスフレーズは端末へ隠して入力し、引数やログに保存しません。暗号化ファイルは別のPCへ持ち出せますが、復号パスフレーズも本人が保管してください。

## ツールを再配布する

このZIP、`SHA256SUMS.txt`、[公開時の説明](docs/REDISTRIBUTION.ja.md)をセットで渡してください。生成したファーム、`.private`、個体のレポートや鍵をZIPへ追加しないでください。公表用の実機実績は上の表の範囲を維持し、全無線SEC002導入まで実機検証済みとは表記しないでください。
