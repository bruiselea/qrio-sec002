# Qrio Q-SL1 ローカル操作・HomeKit中継ツール

初代 **Qrio Smart Lock（Q-SL1）** を、登録済みの所有者鍵で施解錠し、iPhoneの「ホーム」から操作するためのコードと手順です。玄関にXIAO ESP32C3を置くことで、鍵から離れたラズパイへLAN経由で接続できます。

本体の既知の保守用アクセスを閉じる **SEC002差分パッチ** も収録しています。中継と本体ファームの対策は、それぞれ独立した機能です。

**[LAN中継のセットアップ](relay/README.ja.md)** ／ **[常駐・HomeKitの設定](relay/SYSTEMD_HOMEKIT.ja.md)** ／ **[SEC002本体ファームの説明](README.ja.md)**

## 何ができる？

| やりたいこと | 提供するもの |
| --- | --- |
| PC・ラズパイから施錠／解錠する | 登録済み所有者鍵を使うコマンドライン操作・認証処理 |
| iPhoneの「ホーム」から操作する | MQTTゲートウェイと、Home AssistantのHomeKit Bridgeへつなぐ手順 |
| ラズパイを玄関から離して置く | XIAO ESP32C3による暗号化Wi-Fi／Bluetooth中継 |
| 所有者認証を自宅で処理する | 所有者秘密鍵をラズパイ側に保持する構成 |
| 本体の既知の保守用経路を閉じる | SEC002の独自差分・生成ツール・初回導入手順 |

施解錠の運用時は、自宅の機器で認証と操作を処理します。セットアップ時のソフト取得にはインターネット接続が必要です。

## どうつながる？

```text
iPhone「ホーム」
      ↓ 自宅LAN
Home Assistant ＋ MQTT ＋ ラズパイの操作プログラム
      ↓ 暗号化された自宅LAN（XIAO側は2.4GHz Wi-Fi）
玄関のXIAO ESP32C3 ＋ 外付けアンテナ
      ↓ Bluetooth（BLE）
Qrio Smart Lock Q-SL1
```

鍵の近くのXIAOがBluetoothを担当するため、ラズパイを鍵の近くへ常設する必要がなくなります。XIAOはUSB給電で動かし、Q-SL1との配線は不要です。所有者秘密鍵はラズパイに保持します。

## 何が必要？

### 施解錠・LAN中継に必要なもの

| 必要なもの | 用途・条件 |
| --- | --- |
| 自分のQ-SL1と正常な電池 | 対象は初代Q-SL1。Q-SL2などの後継機は対象外 |
| **登録済みの所有者操作鍵 `owner.json`** | 本体に登録済みの秘密鍵・認証情報を含む操作用JSON |
| ラズパイなどのLinuxホスト | 認証と操作プログラムを実行。Python 3.11以上 |
| Seeed Studio XIAO ESP32C3 | 玄関側のWi-Fi／Bluetooth中継器 |
| 対応する外付け2.4GHzアンテナ | XIAOへ接続して使用 |
| USBデータケーブルとUSB電源 | 初回のXIAO書き込みと、玄関での常時給電 |
| 自宅の2.4GHz Wi-Fi | XIAOとラズパイが通信できるLAN。XIAOのDHCP予約も設定 |
| ビルド用PC | Python 3.12以上。XIAOへの初回書き込みに使用。Windowsの手順を掲載 |

**オーナー登録カードの番号やQRコードだけでは、この公開版で施解錠を始められません。** 新しい所有者の登録や、回復vaultから`owner.json`を取り出す機能は未収録です。登録済み操作鍵を用意できることを、導入前に確認してください。

### iPhoneの「ホーム」から使う場合に追加するもの

- iPhoneと「ホーム」アプリ。
- セットアップ済みのHome Assistantと、認証付きMQTT broker。
- Home AssistantのHomeKit Bridge設定。初回追加はiPhoneと同じLANで行います。

Home AssistantとMQTTの本体インストーラーは含みません。コマンドラインで操作するだけなら、これらやiPhoneは不要です。外出先からのホーム操作には、ホームハブなど別途の設定が必要です。

## どこから始める？

### iPhoneから操作したい／LAN中継を使いたい

1. 登録済みの`owner.json`と、上の機材を用意する。
2. リポジトリの最新ソースを取得する。
3. XIAOへWi-Fi情報と中継ファームを設定する。
4. ラズパイから、中継経由の認証付き状態取得を確認する。
5. 実際の施錠を確認し、常駐サービス・MQTT・HomeKitへ接続する。

```sh
git clone https://github.com/bruiselea/qrio-sec002.git
cd qrio-sec002
```

続きは **[XIAO中継のセットアップ手順](relay/README.ja.md)** へ。順番に使うコマンド、秘密情報の設定、USB書き込みを掲載しています。

中継のセットアップで書き込むのはXIAOです。Q-SL1本体へのSEC002導入は別の作業として判断してください。中継の実機確認はSEC002を導入した1個体で行っています。

### 本体へSEC002の対策を入れたい

[SEC002の説明](README.ja.md)から、対応条件・検証範囲・[初回無線導入](docs/WIRELESS_INSTALL.ja.md)を確認してください。既知の純正`1.4.01`と一致するDS1ハッシュ・配置だけを対象にしています。

**この配布版の純正→SEC002全無線導入は、実機通し試験未実施の実験版です。** SEC002導入後は無線更新経路を閉じるため、以後のファーム保守・起動障害からの救済は有線UARTが必要です。自動ロールバックと汎用UART救済プログラムは含みません。[復旧の制限と準備](docs/RECOVERY.ja.md)を先に確認してください。

## 確認済みのこと・制限

| 項目 | 状況 |
| --- | --- |
| XIAOによるLAN中継 | 1個体で所有者認証・状態取得に成功 |
| iPhoneからの施錠 | ラズパイを離した配置で、本人の施錠確認とモーター正常完了記録を照合 |
| 公開用ランタイム | Windows／ラズパイで中継関連の合成試験13件が通過 |
| SEC002本体 | 同じ1個体で有線導入・起動・既知経路の拒否を確認 |
| 配布版SEC002の全無線導入 | 実機通し試験は未実施 |
| 別個体・長期運転・新規環境の一括構築 | 未確認 |

状態表示は、最後に正常完了したモーター操作から30秒で不明へ戻します。手動つまみの位置追跡は未対応です。通信が切れて結果不明になった操作を、自動で再送しません。

現行の中継構成はラズパイを必要とします。XIAO単体での所有者認証、iPhoneからの直接BLE操作、Apple Walletのホームキー／NFC解錠は実装していません。
