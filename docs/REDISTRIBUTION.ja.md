# 配布のしかた

日本語 | [English](REDISTRIBUTION.en.md)

統合版[v0.9](https://github.com/bruiselea/qrio-sec002/releases/tag/v0.9)は、タグのソース一式`qrio-sec002-v0.9.zip`と`SHA256SUMS-v0.9.txt`を配布します。登録・中継・有線復旧・英語資料を含みます。以下のv0.1.0 ZIPは履歴用の旧配布物です。

本体差分キットの配布単位は`qrio-sec002-toolkit-v0.1.0.zip`と、そのZIP用の`SHA256SUMS.txt`です。最新の登録・中継コードは[リポジトリのソース](https://github.com/bruiselea/qrio-sec002)に収録し、旧v0.1.0 ZIPは変更していません。独自のコード・差分・説明文は同梱MIT Licenseで再配布できます。第三者の純正コードまで同じ許諾で配布できるという意味ではありません。[NOTICE.md](../NOTICE.md)も一緒に残してください。

## 含めるものと含めないもの

同梱物は、独自ツールのPythonソース、248バイト分の独自置換データ、元データのハッシュ、独自アセンブリ、合成テスト、手順、依存の版指定です。`MANIFEST.json`に各ファイルのSHA-256を収録しています。

純正ファーム、生成済みSEC002イメージ、全EEPROM/ROM、SDK、旧公式APK、個体の暗号化バックアップ、オーナーカード、鍵、HomeKit設定、私有ログは配布しません。暗号化済みであっても個体バックアップを同梱しないでください。ローカルで生成したSEC002は純正コードを含むため、このZIPへ追加しません。

依存ライブラリは利用者がPyPIから別途取得します。依存を内包した配布形態へ変更する場合、そのライセンスや必要な告知も別に確認します。

最新ソースを配布する場合、`onboarding/`の登録・vaultツール、`relay/`の中継コード・ESPHome設定と手順は含められます。APK・MQ係数表・ネイティブライブラリー、`.qsl1`と更新前vault、`owner.json`、私有`relay.private.json`、`secrets.yaml`、生成済みXIAOファームは追加しません。独自ソースと、実行時に利用者が用意する第三者データ・個体の秘密情報を区別します。

`wired/`の独自UARTスケッチ・限定復旧コード・合成試験と、`docs/BOOT_FAILURE.ja.md`・`docs/evidence/SEC001.json`も再配布するソースに含められます。C3のビルド生成物、全EEPROMのハッシュやダンプ、暗号化バックアップ、本人の実行記録は追加しません。復旧の適用条件と実機通し試験未実施の表示を残します。

## 公開ページへ添える説明の例

> 所有するQ-SL1向けのSEC002差分パッチ・初回無線導入ツールです。既知の純正1.4.01と一致するDS1配置のみ対応します。純正ファーム・個体鍵は同梱せず、Linux/ラズパイのBluetoothから各自の本体を読み出して適用します。SEC002自体の有線導入と動作、別候補での無線転送・切替を1個体で確認していますが、この配布版による純正→SEC002の全無線導入は実機通し試験未実施の実験版です。導入後の更新・起動障害からの救済にはUARTが必要で、自動ロールバックはありません。UART救済プログラムはこのZIPに含みません。

配布物が用意されたことと、第三者の個体で検証済みであることを混同しないでください。「文鎮化しない」「全脆弱性修正済み」「完全無線で何度でも更新可能」とは案内しません。

## 公開前の確認

- README、無線導入手順、復旧の制限、LICENSE、NOTICE、MANIFESTをセットで残す。
- `python -m unittest discover -s tests -v`を実施し、SHA256SUMSをZIPから再計算する。
- ZIPのファイル一覧を確認し、`.private`、`.qsb`、`.dpapi.json`、バイナリ、鍵や実機ログがないことを確認する。
- ダウンロードリンクは実際に配置できたURLへ差し替える。存在しないGitHub ReleaseのURLは案内しない。

v0.1.0の配布ZIPと最新ソースの収録内容は異なります。再配布するソース一式では、ルートの`MANIFEST.json`と実際のファイルのハッシュを合わせ、検証範囲・対応APKが別途必要な条件も残してください。
